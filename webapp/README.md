# 클라우드 콘텐츠 콘솔

`cloud-console.html`은 클라우드에서 도는 원고 생성기의 원본입니다.
구독으로 동작하므로 원고를 만들 때 API 요금이 붙지 않습니다.

주소: https://claude.ai/code/artifact/0a65c72b-d85f-41bf-8c00-ea62ba8c0ec2

## 쓰는 순서

1. 위 주소에서 제목을 넣고 `원고 생성`
2. `원고 내보내기`를 눌러 원고를 복사
3. 사내 PC의 콘솔 앱(`python main.py content`)에서 `원고 가져오기` 칸에 붙여넣기
4. 검사 · 썸네일 · CMS 업로드는 콘솔 앱이 이어서 처리

## 이 파일을 여기에 두는 이유

발행된 화면만 있으면 원본이 이 저장소 밖에만 남습니다.
검사 규칙(의료법·포지셔닝)이 `content/` 아래 파이썬 모듈과 같은 내용이라,
한쪽을 고치면 다른 쪽도 같이 봐야 합니다. 대조할 수 있게 함께 둡니다.

파일을 고친 뒤에는 발행해야 실제 화면에 반영됩니다.
