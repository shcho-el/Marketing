# 모델 촬영 스케줄러 (Google Sheets 연동 웹앱)

구글 시트 **‘촬영 슬롯’ 탭**을 실시간으로 읽고, 웹앱에서 수정한 내용을 **같은 행에 그대로 다시 기록**하는 Apps Script 웹앱입니다.

| 기능 | 설명 |
|---|---|
| 캘린더 | 월별 달력에 촬영 슬롯 표시 · 센터별 색상, 상태(확정/조율 중/취소/미배정) 점 표시 · 센터/상태/테스트/사용 N 필터 |
| 양방향 연동 | 웹앱에서 일정 추가·수정·삭제 → 시트에 즉시 반영. 시트 변경은 1분마다(또는 새로고침) 웹앱에 반영 |
| 모델 기본 정보 | ‘모델 정보’ 탭(이름·연락처·성별·연령대·선호 연락·촬영 부위·메모)을 웹앱에서 관리 |
| 작업 담당자 | 촬영별 담당자 기재 (시트 `작업 담당자` 열) |
| 콘티 기획안 | 링크 여러 개 + 파일 업로드(Drive ‘촬영 콘티’ 폴더 저장, 파일당 30MB) |
| 상세 새 탭 | 달력의 일정을 클릭하면 **새 탭**에서 촬영 정보·모델 정보·콘티 미리보기(구글 슬라이드/문서/Drive 파일/피그마/유튜브 임베드) |

## 시트 구조

기존 열(A~O)은 **헤더 이름으로 찾기 때문에** 순서가 바뀌어도 됩니다. 헤더는 1행 기준입니다.

`센터 · 일자 · 시간 · 정원 · 사용 · 센터장 확인 · 확정 인원 · 모델 · 메모 · 테스트 · 수동 배정 모델 · 수동 상태 · 캘린더 등록 · 연락 방식 · 비고`

초기 설정 시 오른쪽에 4개 열이 자동 추가됩니다.

| 추가 열 | 형식 |
|---|---|
| 작업 담당자 | 텍스트 |
| 콘티 링크 | 한 줄에 하나씩 `이름 \| URL` |
| 콘티 파일 | 한 줄에 하나씩 `파일명 \| Drive URL` |
| 고유ID | 웹앱이 행을 찾는 키 — **지우거나 수정하지 마세요** |

- **수식이 들어 있는 셀(예: 확정 인원, 모델)은 절대 덮어쓰지 않습니다.**
- 웹앱의 “모델”은 `수동 배정 모델` 열에 기록되고, 비어 있으면 `모델` 열 값을 표시합니다.
- 상태·연락 방식·센터 선택지는 시트의 드롭다운(데이터 확인) 목록을 그대로 사용합니다.

## 설치 (약 5분)

1. 구글 시트 열기 → **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](Code.gs) 붙여넣기
3. 왼쪽 **+ → HTML** → 이름을 `Index` 로 만들고 [`Index.html`](Index.html) 붙여넣기
4. ⚙ 프로젝트 설정 → **‘appsscript.json’ 매니페스트 파일 표시** 체크 → `appsscript.json` 내용을 [`appsscript.json`](appsscript.json)으로 교체 (시간대 Asia/Seoul)
5. 저장 후 상단 함수 선택에서 **`setup` 선택 → 실행** → 권한 승인
   - 추가 열 4개, 고유ID, ‘모델 정보’ 탭(기존 모델 이름으로 자동 채움), Drive ‘촬영 콘티’ 폴더가 생성됩니다.
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **도메인 내 모든 사용자** (회사 Google Workspace) / 개인 계정이면 **Google 계정이 있는 모든 사용자**
7. 발급된 웹앱 URL(`…/exec`)을 팀에 공유하세요. 시트를 새로고침하면 상단 **촬영 스케줄러** 메뉴에서도 주소를 볼 수 있습니다.

> 코드를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 권한 · 보안 메모

- “실행 사용자: 나”로 배포하면 웹앱 사용자는 시트 편집 권한 없이도 웹앱을 통해 수정할 수 있습니다. 접근 범위는 6번의 액세스 권한으로 제한하세요.
- 업로드한 콘티 파일은 배포한 사람의 Drive ‘촬영 콘티’ 폴더에 저장됩니다. 상세 페이지에서 미리보기를 보려면 열람자가 그 폴더에 접근할 수 있어야 하므로, **폴더를 팀과 공유**(뷰어 이상)해 두세요.
- 30MB를 넘는 파일은 Drive에 직접 올리고 링크로 추가하세요.

## 설정 변경

`Code.gs` 상단 `CONFIG`:

| 항목 | 기본값 |
|---|---|
| `SHEET_NAME` | `촬영 슬롯` |
| `MODEL_SHEET_NAME` | `모델 정보` |
| `HEADER_ROW` | `1` |
| `FOLDER_NAME` | `촬영 콘티` |
