# 모델 촬영 스케줄러 (Google Sheets 연동 웹앱)

구글 시트 **‘촬영 슬롯’ 탭**을 실시간으로 읽고, 웹앱에서 수정한 내용을 **같은 행에 그대로 다시 기록**하는 Apps Script 웹앱입니다.

| 기능 | 설명 |
|---|---|
| 캘린더 | 월별 달력에 촬영 슬롯 표시 · 센터별 색상, 상태(확정/조율 중/취소/미배정) 점 표시 · 센터/상태/테스트/사용 N 필터 |
| 양방향 연동 | 웹앱에서 일정 추가·수정·삭제 → 시트에 즉시 반영. 시트 변경은 1분마다(또는 새로고침) 웹앱에 반영 |
| 모델 기본 정보 | ‘모델 정보’ 탭(이름·연락처·성별·연령대·선호 연락·촬영 부위·메모)을 웹앱에서 관리 |
| 작업 담당자 | 촬영별 담당자 기재 (시트 `작업 담당자` 열) |
| 콘티 기획안 | 링크 여러 개 + 파일 업로드(Drive ‘촬영 콘티’ 폴더 저장, 파일당 30MB) |
| 상세 새 탭 | 달력의 일정을 클릭하면 **새 탭**에서 촬영 정보·모델 정보·콘티 미리보기(구글 슬라이드/문서/Drive 파일/피그마/유튜브 임베드) |

## 시트 구조

기존 열(A~O)은 **헤더 이름으로 찾기 때문에** 순서가 바뀌어도 됩니다. 헤더는 1행 기준입니다.

`센터 · 일자 · 시간 · 정원 · 사용 · 센터장 확인 · 확정 인원 · 모델 · 메모 · 테스트 · 수동 배정 모델 · 수동 상태 · 캘린더 등록 · 연락 방식 · 비고`

초기 설정 시 오른쪽에 4개 열이 자동 추가됩니다.

| 추가 열 | 형식 |
|---|---|
| 작업 담당자 | 텍스트 |
| 콘티 링크 | 한 줄에 하나씩 `이름 \| URL` |
| 콘티 파일 | 한 줄에 하나씩 `파일명 \| Drive URL` |
| 고유ID | 웹앱이 행을 찾는 키 — **지우거나 수정하지 마세요** |

- **수식이 들어 있는 셀(예: 확정 인원, 모델)은 절대 덮어쓰지 않습니다.**
- 웹앱의 “모델”은 `수동 배정 모델` 열에 기록되고, 비어 있으면 `모델` 열 값을 표시합니다.
- 상태·연락 방식·센터 선택지는 시트의 드롭다운(데이터 확인) 목록을 그대로 사용합니다.

## 설치 (약 5분) — 기존 시트·스크립트를 건드리지 않는 방식

시트에 이미 붙어 있는 Apps Script(예약 자동화 등)가 있을 수 있으므로, **시트의 확장 프로그램 → Apps Script에는 붙여넣지 않습니다.**
대신 **별도(독립) 프로젝트**로 만들어 시트 ID로 연결합니다. 기존 코드는 그대로 유지됩니다.

### 1단계: 사본으로 먼저 테스트 (권장)
1. 원본 시트에서 **파일 → 사본 만들기** → 사본 주소의 `/d/` 와 `/edit` 사이 ID 복사
2. [script.google.com](https://script.google.com) → **새 프로젝트** (이름: 촬영 스케줄러)
3. `Code.gs` 에 이 폴더의 [`Code.gs`](Code.gs) 붙여넣기 → 상단 `SPREADSHEET_ID` 를 **사본 ID** 로 교체
4. 왼쪽 **+ → HTML** → 이름 `Index` → [`Index.html`](Index.html) 붙여넣기
5. ⚙ 프로젝트 설정 → **‘appsscript.json’ 매니페스트 파일 표시** → [`appsscript.json`](appsscript.json) 내용으로 교체
6. 함수 선택에서 **`setup` → 실행** → 권한 승인 (실행 로그에 완료 메시지 확인)
7. **배포 → 테스트 배포 → 웹 앱** 주소로 열어 일정 추가·수정·콘티 업로드를 해 보고, 사본 시트에 제대로 기록되는지 확인

### 2단계: 원본에 연결
1. `SPREADSHEET_ID` 를 원본 ID(`1qFVE2hgnAj6nEE_blqUBr18rqrvQtXX6T_W8nQZq1mM`)로 바꾸고 저장
2. 원본 시트에서 **파일 → 버전 기록 → 현재 버전 이름 지정** (예: “스케줄러 연결 전”)
3. **`setup` 다시 실행**
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **도메인 내 모든 사용자** (회사 Google Workspace) / 개인 계정이면 **Google 계정이 있는 모든 사용자**
5. 발급된 웹앱 URL(`…/exec`)을 팀에 공유

> 코드를 수정했다면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다.

## 되돌리기

스케줄러가 원본에 만드는 변경은 아래 3가지뿐이고, 기존 A~O 열의 값은 웹앱에서 수정한 셀 외에는 바뀌지 않습니다.

| 변경 | 되돌리는 법 |
|---|---|
| 촬영 슬롯 오른쪽 열 4개 (작업 담당자·콘티 링크·콘티 파일·고유ID) | 해당 열 삭제 |
| ‘모델 정보’ 탭 | 탭 삭제 |
| Drive ‘촬영 콘티’ 폴더 | 폴더 삭제 |
| 웹앱 | 배포 관리 → 보관처리, 또는 Apps Script 프로젝트 삭제 |

웹앱에서 수정한 값까지 되돌리려면 **파일 → 버전 기록**에서 2단계-2에 이름 붙인 버전을 복원하세요.
(단, 복원하면 그 이후 다른 사람이 시트에 입력한 내용도 함께 되돌아가니, 필요한 셀만 버전 기록에서 확인해 고치는 것이 안전합니다.)

## 권한 · 보안 메모

- “실행 사용자: 나”로 배포하면 웹앱 사용자는 시트 편집 권한 없이도 웹앱을 통해 수정할 수 있습니다. 접근 범위는 6번의 액세스 권한으로 제한하세요.
- 업로드한 콘티 파일은 배포한 사람의 Drive ‘촬영 콘티’ 폴더에 저장됩니다. 상세 페이지에서 미리보기를 보려면 열람자가 그 폴더에 접근할 수 있어야 하므로, **폴더를 팀과 공유**(뷰어 이상)해 두세요.
- 30MB를 넘는 파일은 Drive에 직접 올리고 링크로 추가하세요.

## 화면 코드 수정 시

`Index.html`은 자동 생성 파일입니다. 화면을 고칠 때는 `src/Index.src.html`을 수정한 뒤 `python3 build.py`로 `Index.html`을 다시 만드세요.
(구글 화면 변환 과정에서 스크립트 글자가 바뀌어 문법 오류가 나는 문제가 있어, 스크립트를 base64로 감싸 넣습니다.)

## 설정 변경

`Code.gs` 상단 `CONFIG`:

| 항목 | 기본값 |
|---|---|
| `SPREADSHEET_ID` | 원본 시트 ID (테스트 시 사본 ID로 교체) |
| `SHEET_NAME` | `촬영 슬롯` |
| `MODEL_SHEET_NAME` | `모델 정보` |
| `HEADER_ROW` | `1` |
| `FOLDER_NAME` | `촬영 콘티` |
