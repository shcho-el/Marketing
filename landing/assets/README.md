# assets

전달받은 원본에서 생성해 **모두 반영 완료** 상태입니다.

| 파일 | 용도 | 규격 |
|------|------|------|
| `logo.png` | 헤더 / 푸터 워드마크 | 843×144, 알파 채널 포함 |
| `logo-white.png` | 어두운 배경용 (예비) | 843×144 |
| `favicon.png` | 브라우저 탭 아이콘 | 512×512 |
| `hero-songdo.jpg` | 히어로 **좌측** — 호라이즌 그린 마블 라운지 | 900×600 |
| `hero-jongno.jpg` | 히어로 **우측** — 오리진 브론즈 로비 | 1376×768 |
| `og.jpg` | 카카오·페북 공유 썸네일 (두 지점 반반) | 1200×630 |

## 참고

- 원본 로고는 이미 배경이 투명한 파일이라 누끼 없이 트림만 했습니다.
  다른 로고로 교체할 때 흰 배경 파일이라면 `python landing/tools/logo_cutout.py <파일>` 로 처리하면 됩니다.
- 히어로는 화면 절반을 세로로 채우므로 `object-fit: cover` 로 좌우가 잘립니다.
  현재 원본(900×600 / 1376×768)은 고해상도 디스플레이에서 다소 부드럽게 보일 수 있으니,
  **세로가 긴 고해상도 원본**(1400×1800 이상)이 있으면 같은 파일명으로 덮어쓰기만 하면 됩니다.
- 파일이 없어도 페이지는 깨지지 않습니다 — 로고는 Cormorant Garamond 텍스트 워드마크로,
  히어로는 각 지점 인테리어 톤 그라디언트로 자동 대체됩니다.
