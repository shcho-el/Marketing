# 오블리브 통합 게이트 페이지

브랜드검색광고(네이버) 랜딩용 **원 페이지**. 오블리브 종로 오리진의원 / 오블리브 송도 호라이즌의원
두 지점의 공통 진입점으로, 광고 소재에서 이 한 개 URL만 걸면 됩니다.

- 파일: `landing/index.html` (외부 빌드 없음 · 단일 HTML)
- 구성: 헤드카피 → 진료센터 3개(피부·체형 / 문제성발톱 / 재활의학 바디랩) → 통합 예약(채널톡) → 오시는 길(지점 구분) → 푸터

## 채널톡 연결

1. 채널톡 관리자 → **채널설정 → 보안 및 개발 → 플러그인 키** 복사
2. `index.html` 하단 스크립트의 `CHANNEL_PLUGIN_KEY` 값 교체
3. 두 지점을 한 채널에서 받을 경우 별도 설정 불필요. 지점별로 나누려면
   채널톡 **워크플로우**에서 첫 질문을 "방문 희망 지점"으로 두고 담당자 라우팅

동작 방식
- 페이지의 모든 `상담·예약` 버튼은 `data-cta="channel"` → 채널톡 메신저 오픈
- 오시는 길 카드의 `예약 문의` 버튼은 `data-branch` 값(종로/송도)을 상담 프로필에 함께 전달
- 플러그인 키가 미설정 상태면 자동으로 **전화 연결**로 대체되므로, 키가 없어도 페이지는 깨지지 않습니다

## 로컬 확인

```bash
cd landing && python3 -m http.server 8080
# http://localhost:8080
```

## 배포

정적 파일 하나라 어디든 올라갑니다. 광고 심사 대응상 **기존 도메인 하위 경로** 권장.

- 예: `https://obliv.kr/gate/` 또는 `https://obliv.kr/brand/`
- 네이버 브랜드검색은 랜딩 URL의 소유 확인이 필요하므로 신규 도메인보다 기존 도메인이 안전합니다
- GitHub Pages로 임시 검수용 배포도 가능

## 반응형 / 접근성

- 860px 이하에서 하단 고정 바(전화 / 오시는 길 / 상담·예약) 노출
- `prefers-reduced-motion` 대응
- 지도는 API 키 없이 동작하도록 네이버지도·카카오맵 검색 링크로 연결
