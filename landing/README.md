# 오블리브 통합 게이트 페이지

브랜드검색광고(네이버) 랜딩용 **원 페이지**. 오블리브 종로 오리진의원 / 오블리브 송도 호라이즌의원
두 지점의 공통 진입점으로, 광고 소재에서 이 한 개 URL만 걸면 됩니다.

```
landing/
├─ index.html            ← 페이지 본체 (단일 파일, 빌드 없음)
├─ assets/               ← 로고·OG 이미지
└─ tools/logo_cutout.py  ← 로고 누끼 스크립트
```

구성

1. **히어로** — 좌 호라이즌 / 우 오리진 메인 인테리어를 좌우로 깐 풀블리드 비주얼 + 헤드카피
2. **상담 신청 바** — 히어로에 겹쳐 올라오는 최상단 접수 폼 (지점 / 이름 / 연락처 / 동의)
3. **진료 클리닉 3개** — 피부체형 / 문제성발톱 / 재활의학(바디랩)
4. **통합 예약** — 채널톡
5. **오시는 길** — 지점별 카드
6. **푸터** — 두 지점 사업자 정보

## 키컬러

| 지점 | 변수 | 값 | 적용 범위 |
|------|------|----|----------|
| 서울 오리진 | `--jongno` | `#794909` | 전역 기본 컬러(버튼·예약 섹션), 종로 카드 |
| 송도 호라이즌 | `--songdo` | `#d8815c` | 섹션 라벨, 송도 카드 |

전달받은 컬러칩에서 추출한 값입니다. 바꿀 일이 생기면 `index.html` 상단 `:root` 의
`--jongno` / `--songdo` 두 줄만 고치면 페이지 전체가 따라 바뀝니다. (`-2` 는 호버용 진한 톤, `-soft` 는 배경용 옅은 톤)

## 로고 · 이미지

전달받은 원본으로 `assets/` 에 모두 생성해 반영했습니다 (로고·파비콘·히어로 2컷·OG).
자세한 규격은 `assets/README.md` 참고.

로고를 다른 파일로 교체할 때 흰 배경이라면:

```bash
pip install pillow
python landing/tools/logo_cutout.py ~/Downloads/obliv-logo.png
```

## 남은 확인 항목

`index.html` 에서 `TODO` 로 검색하면 전부 나옵니다. 진료시간은 화면에서도 빨간색으로 표시됩니다.

| 항목 | 현재 값 | 비고 |
|------|---------|------|
| 종로 진료시간 | 평일 10:00–21:00 (가안) | 야간 21시 운영만 확인됨 |
| 송도 진료시간 | 평일 10:00–19:00 (가안) | 확인 필요 |
| 채널톡 플러그인 키 | `YOUR_CHANNEL_TALK_PLUGIN_KEY` | 아래 참고 |
| 의료광고 심의번호 | 미기재 | 심의 후 푸터 삽입 |
| 클리닉별 상세 링크 | obliv.kr / oblivseoul.kr | 상세 페이지 URL로 교체 |

지점 정보(주소·대표번호·대표자·사업자등록번호·이메일)는 전달받은 값으로 반영 완료.

## 채널톡 연결

1. 채널톡 관리자 → **채널설정 → 보안 및 개발 → 플러그인 키** 복사
2. `index.html` 하단 `CHANNEL_PLUGIN_KEY` 값 교체
3. 지점별로 담당자를 나누려면 채널톡 **워크플로우** 첫 질문을 "방문 희망 지점"으로 설정

동작 방식
- 상단 **상담 신청 바** → 입력값 검증 후 채널톡을 열고
  `[상담 신청] 희망 지점 / 성함 / 연락처` 를 메시지로 미리 채워 전송 대기 상태로 넘김
  (`ChannelIO('updateUser')` 로 상담 프로필에도 동일 값 기록)
- 모든 `상담·예약` 버튼(`data-cta="channel"`) → 채널톡 메신저 오픈
- 오시는 길의 `예약 문의` 버튼은 지점값(`data-branch`)을 상담 프로필로 함께 전달
- 키 미설정 시 자동으로 **선택한 지점의 전화 연결**로 대체 → 키가 없어도 페이지 정상 동작

## 로컬 확인

```bash
cd landing && python3 -m http.server 8080   # http://localhost:8080
```

## 배포

정적 파일이라 어디든 올라갑니다. 광고 심사 대응상 **기존 도메인 하위 경로** 권장
(예: `https://obliv.kr/gate/`). 네이버 브랜드검색은 랜딩 URL 소유 확인이 필요해
신규 도메인보다 기존 도메인이 안전합니다.

## 반응형 / 접근성

- 900px 이하에서 하단 고정 바(전화 / 오시는 길 / 상담·예약) 노출
- `prefers-reduced-motion` 대응
- 지도는 API 키 없이 동작하도록 네이버지도·카카오맵 검색 링크로 연결
