실제 데이터 연결하기 (3단계)

1
네이버 API 키 발급
developers.naver.com에서 앱 등록 → "검색" API 선택 → Client ID / Secret 발급
2
API 키 설정
프로젝트 폴더에 .env 파일 생성:

NAVER_CLIENT_ID=발급받은_ID
NAVER_CLIENT_SECRET=발급받은_SECRET
3
실행
pip install -r requirements.txt
python main.py all → http://localhost:5000 접속
