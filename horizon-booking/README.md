# 송도 호라이즌 촬영 일정 신청 (선정자용)

기존 촬영 일정 신청 페이지와 별개인 새 Google Apps Script 웹앱입니다.

## 처음 설정 (10분)

1. https://script.google.com 에서 **새 프로젝트**를 만들고 이름을 `송도 호라이즌 촬영 일정 신청`으로 바꿉니다.
2. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여 넣습니다.
3. 왼쪽 `+` → **HTML** → 이름 `Index` 로 파일을 만들고 `Index.html` 내용을 붙여 넣습니다.
4. `Code.gs` 위쪽 `CONFIG`에서 확인할 것
   - `CONTACT`: 일정 변경·문의 담당자 이름·전화·이메일 (비우면 화면에서 숨김)
   - `TIMES`: 시작 가능 시각 (기본 10·11·14·15·16·17시)
   - `MAX_PER_SLOT`: 한 시간대 인원 (기본 1명)
   - `WEEKS_AHEAD`: 내일부터 몇 주까지 보일지 (기본 6주)
   - `BLOCKED_DATES`: 촬영 없는 수·목 (예: `'2026-12-24'`)
5. 위쪽 함수 목록에서 `setup` 선택 → **실행** → 권한 승인. Drive의 `인천재활모델지원` 폴더에 `촬영일정_신청` 시트(초대·응답 탭)가 만들어집니다.
6. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포.

## 선정자에게 링크 보내기

1. `촬영일정_신청` 시트의 **초대** 탭에 선정자 정보를 적습니다. (이름 · 전화번호 · 이메일 · 지원 항목(재활/발톱)), 초대 코드·링크 칸은 비워 둡니다.
2. Apps Script에서 `makeInviteLinks` 실행 → **신청 링크** 칸에 사람마다 링크가 생깁니다.
3. 그 링크를 문자·메일로 보냅니다. 링크로 들어오면 이름·전화·이메일이 미리 채워지고, 지원 항목에 맞는 장소가 보입니다.

## 신청이 들어오면

- **응답** 탭에 한 줄로 기록됩니다. (희망 1~3순위, 주소, 서류 링크)
- 신분증·통장 사본은 해당 지원자 폴더 안 **계약서류** 폴더에 저장됩니다. (기존 지원자 폴더가 있으면 그 안에, 없으면 새로 만듦)
- 담당자에게 알림 메일이 갑니다.
- 한 링크로는 한 번만 신청할 수 있고, 초대 탭의 **신청 상태**가 `신청 완료`로 바뀝니다.
- 1순위로 이미 찬 시간대는 다른 사람 화면에 `마감`으로 보입니다.

## 코드를 고친 뒤

배포 → **배포 관리** → 연필 → 버전 **새 버전** → 배포. (링크는 그대로 유지됩니다)
