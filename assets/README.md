# 썸네일 소재

## 로고 — `assets/logo.png`

배경을 지운(누끼) **투명 PNG**로 넣어 주세요.
어두운 사진 위에 올라가므로 원본이 진한 글자여도 괜찮습니다.
알파 채널의 글자 모양만 남기고 크림색으로 다시 칠해서 얹습니다.

- 권장 가로 폭: 600px 이상 (축소해서 쓰므로 크게 넣어도 됩니다)
- 배경이 흰색으로 남아 있으면 사진 위에 흰 네모가 그대로 얹힙니다. 반드시 투명 배경으로 저장하세요.
- 색을 그대로 쓰려면 `.env`에 `THUMB_LOGO_TINT=0`

## 배경 사진 — `assets/thumbnails/`

```
assets/thumbnails/
  ├─ 공용사진1.jpg          ← 카테고리 폴더가 없을 때 사용
  ├─ 공용사진2.jpg
  ├─ 발톱무좀치료/
  │    ├─ foot01.jpg
  │    └─ foot02.jpg
  └─ 내성발톱치료/
       └─ nail01.jpg
```

- 카테고리 폴더가 있으면 그 안에서 고르고, 없으면 상위 폴더에서 고릅니다.
- 글의 포스트URL을 해시해서 고르므로 **같은 글은 항상 같은 사진**이 나옵니다.
  다시 생성해도 썸네일이 바뀌지 않습니다.
- 880×580으로 잘려 들어가므로 가로 1400px 이상을 권장합니다.
- jpg / jpeg / png / webp

### 의료법 주의

배경 사진에 **시술 전후 비교 사진을 쓰지 마세요.**
의료법 제56조 제2항 제4·5호에 따라 시술 장면·전후 사진은 노출 방식과
중요정보 기재 여부에 따라 제한됩니다. 일반적인 인물·피부 이미지를 쓰고,
사용권이 확보된 사진인지 반드시 확인하세요.

사진이 하나도 없으면 단색 배경으로 만들어집니다(글은 정상 저장됨).
