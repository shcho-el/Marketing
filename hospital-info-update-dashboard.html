기본은 개인 저장 모드(내 브라우저에만 저장)입니다. 아래로 Firebase 실시간 DB를 연결하면 링크를 공유받은 팀원 모두가 같은 체크·입력값을 실시간으로 공유합니다.
  1. console.firebase.google.com 접속 → 구글 계정 로그인 → 프로젝트 만들기 (무료)
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 선택 → 테스트 모드로 시작
  3. 프로젝트 설정(⚙️) → 내 앱 → 웹앱(</>) 추가 → 표시되는 firebaseConfig 값 복사
  4. 이 파일 상단 스크립트의 FIREBASE_CONFIG 에 붙여넣기 (특히 databaseURL 필수) 후 저장·푸시
  5. 끝! 상단 표시가 “● 팀 공유 연결됨” 으로 바뀌고, 링크를 받은 모든 팀원이 실시간으로 함께 체크합니다.
